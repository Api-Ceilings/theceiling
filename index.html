What this is

If you hit a 429 — or a 503, or a 403 that might be one — the number you need is three seconds away.

Each page is a dated record of what that API actually publishes, plus the part the docs skip:

  • The limit by tier, auth method, scope, or distribution model
  • The exact error shape your code will receive, verbatim
  • Retry logic that honours whatever header that API actually sends
  • One escape hatch if you're still stuck

Every number is dated. Every page carries the source it came from, on the date it was checked. If you find a discrepancy, open an issue — corrections are the point.

The Ceiling is free, ad-free, and tracking-free. No email, no signup, no newsletter. Nothing on this page collects anything about you.
