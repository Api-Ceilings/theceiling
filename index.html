What this is

If you hit a 429 — or a 403 that might be one — and need to know why and what to do next, this is for you. Each page shows:

  • The current rate limit by usage tier or authentication method
  • The exact error shape your code will receive
  • Retry logic that handles the Retry-After header
  • One escape hatch if you're stuck

Every number is dated. Every page carries the source it came from. If you find a discrepancy, open an issue.

The Ceiling is a free, ad-free, tracking-free reference. No email required, no signup, no newsletter.
